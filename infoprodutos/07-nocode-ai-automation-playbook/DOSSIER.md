## 1. Validação

- **Categoria:** No-code automation + AI tools — busca alta profissional ("save time with AI/automation"), buyers dispostos a pagar USD para economizar horas.
- **Onde vende:** Gumroad (automation packs $39–$99), YouTube→Lemon funnels. Concorrentes: "AI Automation Agency" cursos $200+ (caros, longos) → brecha para playbook direto $49.
- **Avatar:** freelancer/agency/solopreneur com 5–20h/semana em tarefa repetitiva (lead triage, follow-up, posting, invoice chase). Sabe planilha, nunca abriu Make.
- **Transformação:** de "copia/cola manual todo dia" → "12 automações importáveis + 1ª rodando hoje".

## 2. Oferta

**Formato:** Playbook 70p + 12 blueprints importáveis (Make JSON + Zap templates links) + 6 vídeos curtos (5–8min cada) + prompt library + cost calculator.

**12 automações (3 trilhas):**
- LEADS (4): IG/Tally form → Sheets/Notion CRM + instant e-mail/Slack; lead scoring GPT; auto-follow-up 3/7 dias; call booking + reminder.
- CONTENT & SALES (4): idea → draft → Notion calendar; repurpose (blog→X/LinkedIn/Reel script); testimonial request + wall update; abandoned cart/DM → nudge.
- OPS & MONEY (4): invoice created → reminder seq; payment → thank + review ask; weekly money digest; support inbox triage + draft replies.
Cada: blueprint + setup map (screenshot numerado) + test script + "if breaks" fix + cost (ops/mês).

**Plus (+$30):** 4 advanced (RAG-lite FAQ bot, proposal generator, churn saver, affiliate payout digest) + 1 teardown vídeo da sua stack + directory de 30 tools com pricing.

**Fixes:**

3. Cost honesty: ops/mês por workflow + plano gratuito até onde dá (Make free vs Core).
4. Prompts versionados (GPT-4o/Claude) + eval checklist (output bom/ruim exemplos).
