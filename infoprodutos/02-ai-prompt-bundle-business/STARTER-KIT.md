## A. Template padrão (colar em TODOS)

```
### [#001] [Nome da tarefa]
**USE WHEN:** [situação]
**TOOL:** ChatGPT / Claude / Any
**LEVEL:** Beginner / Pro
**FILL:** [entre colchetes o que personalizar]
**PROMPT (copy-paste):**
> [prompt completo, com Role + Context + Task + Format + Constraints + Example]
**EXPECTED OUTPUT:** [o que vem + como avaliar]
**PRO TIP:** [1 linha para melhorar]
```

Exemplo de prompt bem formado (Role+Context+Task+Format):

> Act as a direct-response copywriter for freelancers. Context: I sell [service] to [audience], price $[X], proof: [1 result]. Task: write a 120-word Upwork proposal: hook (1 line referencing job post), plan (3 bullets), proof (1 line), CTA (1 question). Constraints: no buzzwords, US English, confident tone. Job post: [paste].

> You are expanding a prompt bundle. Category: [X]. Generate 50 NEW distinct tasks (no overlap with list: [paste existing titles]). For each, output in my template (USE WHEN/TOOL/LEVEL/FILL/PROMPT/EXPECTED/PRO TIP). Prompts must be copy-paste ready, with [brackets], Role+Context+Task+Format+Constraints. US English, actionable, no fluff. Number them #061–#110.

Curadoria humana obrigatória: rode 5 de cada 50 ao vivo, ajuste, printe 1 output de exemplo por categoria para a sales page.
