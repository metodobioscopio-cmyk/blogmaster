# STARTER-KIT #4 — ADHD Focus System (base)

## A. Today page (Notion spec)

- Top: `Energy check` (select: 🔴 Low / 🟡 Medium / 🟢 High) + `Sleep` (number) + `One word` (text).
- `🎯 Today's 3 MITs` (relation Tasks, limit 3 — linked view filtered `MIT=true AND Date=today`, sort Priority). Formula aviso: `if(count>3,"⛔ Pick only 3 — move the rest to Dump","")`.
- `⏳ Timebox` (table simples 6:00–22:00 em blocos 30min? Não — simplifique: 3 blocos: Morning Block / Afternoon Block / Evening Block, cada com 1 MIT + 1 shallow).
- `Shallow pit` (max 3 tarefas <15min).
- `Wins tonight` (3 linhas: done/grateful/tomorrow MIT #1).
- Botão: `🌙 Shutdown-5` → abre checklist (template).

**DB Tasks props:** Task(title), Date(date), MIT(checkbox), Project(relation), Energy(select: Low/Med/High), Size(S/M/L ~ 10m/30m/90m), Done(checkbox), Dump origin?(checkbox).

## B. Brain Dump + triage (o coração)

- Inbox: DB Dump (Title, Created, Triaged checkbox). Quick-add button no Today + mobile widget-friendly.
- Triage view (board 4 colunas): `⚡ Do (<2min, agora)` / `📅 Schedule (vira Task com data)` / `📁 Someday (DB Someday)` / `🗑️ Delete (sem culpa)`. Regra escrita na página: "Touch once. 2 minutes or schedule it."
- Weekly auto: itens >7 dias sem triage vão para `Stale (forgive & delete?)` — anti-acúmulo.

## C. Routines (checklists clicáveis)

**Morning-5 (5min):** water + meds? / energy check / pick 3 MITs / timebox 3 blocks / open today's 1st MIT tab (só 1!).
**Shutdown-5 (5min):** check MITs done / dump open loops (2min) / pick tomorrow MIT #1 / close tabs (bookmark burst) / win of the day.
**Weekly-15 (script):** 1) wins (3) 2) leaks (where did time go? top 2) 3) dump triage full 4) next week MITs (top 5 for week) 5) 1 system tweak (só 1!).
**Bad Day Protocol (página):** "Rough day? Do ONLY this: 1 MIT of 10 minutes (smallest slice), 1 reset from Dopamine Menu (Low), forgive the rest. Streak counts if ≥1 MIT. You're still in the game. 💛"

## D. Dopamine Menu (30 itens starter — expandir)

- Low energy (10): stretch 3min, tea ritual, window light 2min, tidy 1 surface, voice-note dump, shower reset, fav song + walk, doodle, cold water face, lie flat breathe 4-7-8.
- Medium (10): 10min walk no phone, inbox zero sprint 10min, 1 small win task, call friend 5min, cook snack, plant/water, journal 5 lines, stretch flow YT 10min, library/café move, color page.
- High (10): run/dance 15min, deep work 25min Pomodoro, batch errands, workout, big MIT slice, teach/learn 20min, side hustle sprint, rearrange desk, long walk podcast, weekend adventure plan.
- Cada item: time + no-screen tag where true.
