# STARTER-KIT #9 — Side Hustle Starter (base: quiz + 3 one-pagers modelo + calculators)

## A. Quiz picker (8 perguntas — scoring 1–5)

1. Hours/week? (<5 / 5–10 / 10+) 2. Startup budget? ($0 / <$100 / <$200) 3. Show face? (never/sometimes/yes) 4. Best skill? (write/design/systems/teach/none-yet) 5. English level? (A2/B1/B2+/native) 6. Want clients? (no/maybe/yes) 7. Speed vs scale? (cash this month / build asset) 8. Tools owned? (phone only / laptop / laptop+)
Scoring matrix (tabela 15×8 no ebook + sheet auto): ex: Faceless products = face-never +5, cash-fast +3, write +2…; UGC = face-sometimes +5, phone-only +4; AI services = systems +5, clients-yes +4.
Output: top 3 + "avoid for now" 2 + link to one-pagers. Implemente como: Google Form? Não — planilha com dropdowns + SCORE (SUMPRODUCT) + conditional top 3 highlight (funciona offline, sem tool).

## C. 3 one-pagers prontos (modelo — complete os 12 no padrão)

**1. Faceless digital products — $300–$2k/mo:** 7h/wk, $20 start (Canva free + Lemon $0 + domain opt), skill 2/5, first $ 14–30d. Money: $19–$39 products × 15–60 sales (1–3% of views). Steps: lane quiz → 1 product weekend → Beacons+Lemon → 30 posts → affiliates. Pitfalls: 5 products, 0 posts (fix: 1/1/30 rule); pretty no-demo page (fix: Loom); quitting day 12 (fix: tracker). Math: 3k views/mo × 2% × $27 = $1,620. Next: #5+#6+#10.
**2. Templates (Notion/Sheets) — $200–$1.5k/mo:** 6h/wk, $0 start, skill systems 3/5, first $ 10–25d. Money: $19–$29 × 10–50 + bundle. Steps: pick avatar → clone top 3 struct → Bridge 3 fixes → demo video → Pinterest 5/dia. Pitfalls: blank-template (fix: dummy data); no video (fix: 5min Loom); 25 views clutter (fix: 5 max). Math: 2k views × 2.5% × $24 = $1,200. Next: #1/#3.
**9. AI services lite — $800–$3k/mo (client, higher):** 8h/wk, $30 start (Make free + GPT), skill 3/5, first $ 7–21d (outreach). Money: $300–$900 setup + $100–$300/mo care × 2–5 clients. Steps: 1 offer (lead→reply + follow-up) → demo video → 20 outreach/day → trial → retainer. Pitfalls: 10 offers (fix: 1); free work forever (fix: paid trial); no maintenance (fix: care plan). Math: 2 clients × $500 + $150/mo = $1,300/mo. Next: #7.

## D. Calculators (sheet 3 abas)

- **Pick calc:** quiz scoring auto (dropdowns → top 3).
- **Money calc:** inputs (hrs/wk, price, conv %, views or outreach/dia) → $/mo + $/h real. Presets por modelo (15 linhas).
- **Runway calc:** weeks to first $ × hrs = total invest; break-even sales = costs/price.

## E. 7-day cards (printable 15×7? Não — 1 card genérico + 15 mini)

- Card genérico (1p): D1 Decide (quiz+top1) / D2 Offer (1-pager steps 1–2) / D3 Build (steps 3–4) / D4 Page (Lemon+demo) / D5 Traffic (10 posts/pins/DMs) / D6 Proof (beta+testimonial) / D7 Review (numbers+next 7). Checkbox + timebox.
- 15 minis (1/4 page each): D1–D7 1-liners específicos do modelo (from one-pager).

## F. Chapters intro/outro (5p total — não mindset infinito)

- Intro (2p): rules (1 model 90 days, numbers>motivation, track weekly), how to use quiz+one-pagers+calcs.
- Outro (3p): your next stack (map 15→store products), 90-day review ritual, when to quit/pivot (criteria: 90d + 50 units of effort + <$100? → pivot to top2).
