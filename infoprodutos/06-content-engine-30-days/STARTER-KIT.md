# STARTER-KIT #6 — Content Engine (base: 100 hooks + 10 skeletons + calendário)

## A. 365 Hooks — sistema + 100 starter (complete a 365)

**Regras de hook (colar no guia):** <12 palavras, 1 número OU contraste (stop/start, before/after, $0/$1k), sem clickbait vazio (entregue no vídeo). Tags: [Pillar: Teach/Proof/Build/Pitch] [Niche: freelance/coach/AI/digital/ecom] [Format: demo/B-A/reply/list].

**100 starter (exemplos por pilar — expanda cada linha em 9 variações trocando niche/número):**
- Teach (25): "3 scripts that sell while you sleep" / "Stop posting THIS (do THIS)" / "My 2-hour content batch routine" / "Steal my $27 pricing math" / "5 hooks I reuse every month"…
- Proof (25): "Day 12: first $27 (breakdown)" / "$0 → $1k: the 3 posts that did it" / "I reposted this 4 times (views)" / "Client result in 7 days (receipt)" / "0 → 1,000 followers: what worked"…
- Build (25): "Building product #3 in public" / "What I'd restart today" / "My faceless desk setup ($0)" / "Failed post autopsy (fix)" / "Weekend batch with me (timelapse)"…
- Pitch (25): "Free: 50 hooks (link in bio)" / "The playbook behind these posts 👀" / "Stop guessing content (system)" / "30 days done in 1 weekend?" / "Last chance: launch price ends"…
Expansão: para cada hook, gere 3 variações (contrarian / number-swap / niche-swap) com IA, depois curadoria (cortar 20% fracos).

## B. 10 caption/script skeletons (modelo — faça 30)

**S1 DEMO 30s:** Hook (1s text) → Problem (5s) → Demo 3 taps (15s) → Result (5s) → CTA "Full system in bio".
**S2 B/A 15s:** Before (messy, 3s) → swipe/beat → After (clean, 5s) → 1-line how (4s) → CTA Save.
**S3 REPLY 20s:** Comment screenshot → "Great Q — 3 answers" → 1/2/3 rapid → CTA Follow.
**S4 List carousel (7 slides):** Cover hook → 5 tips (1/slide, <20 words) → CTA slide (freebie). Caption: hook + 3-line story + bullets recap + CTA.
**S5 Story-sell (3 frames):** poll ("struggle with X?") → demo sticker → link ("I made this for you 👀").
**S6–S10:** tutorial thread (X/LinkedIn), Pinterest pin (title+desc+tags), Shorts repurpose (cut first 3s), testimonial frame, launch post.
Cada skeleton = Notion page com [brackets] + exemplo preenchido real do seu nicho.

Checklist + playlist + "done bar" (X/30).
