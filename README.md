## Como usar este repo (terminar 1 a 1)

Cada pasta tem 2 arquivos:

- `DOSSIER.md` → validação + oferta + Bridge & Better + copy da sales page (EN) + precificação Lemon Squeezy + plano de produção 7 dias.
- `STARTER-KIT.md` → **conteúdo inicial REAL** (capítulos, prompts, schemas, specs) para você completar sem começar do zero.

Fluxo por produto (ciclo de 7 dias):

1. Dia 1 — Ler DOSSIER, garimpar 5 concorrentes (Etsy/Gumroad), salvar reviews 3–4★.
2. Dia 2–4 — Completar STARTER-KIT até virar produto (Notion/Sheets/Canva/PDF).
3. Dia 5 — Sales page + mockups + vídeo demo Loom 3–5min.
4. Dia 6 — Subir no Lemon Squeezy (produto + variant + upsell + afiliados 30–50%).
5. Dia 7 — Lançar: 3 pins Pinterest + 3 TikToks/Reels faceless + 1 post Product Hunt/Reddit.
