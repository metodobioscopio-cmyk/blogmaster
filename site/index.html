O diagnóstico

O site ficou pronto.
O crescimento
não veio junto.

Você entrega o site, recebe o pagamento e encerra o projeto. Três meses depois o cliente manda mensagem dizendo que "o site não deu resultado". Não é culpa do layout. O site era linear: uma peça estática que não mede nada, não aprende nada e não se corrige.

A consultoria tradicional resolve isso com três profissionais — analista de SEO, redator e especialista em CRO — e um cronograma de seis semanas. É caro, é lento, e a maioria dos negócios brasileiros simplesmente não contrata.

É exatamente esse intervalo que este curso ocupa. O que antes exigia uma equipe, hoje são seis chamadas de API em sequência — e um método para ler o que elas devolvem.

02 O Funil de Crescimento A sequência

A ordem importa
mais do que a
ferramenta.

A maioria usa IA no lugar errado do processo: começa escrevendo. O método inverte — primeiro mede, depois produz, e só então amplifica.

  1. 01 / EXTRAIR
    Inteligência

    Varra o site dos 3 principais concorrentes: meta, oferta, palavras-chave, contatos.

    → Dossiê competitivo
  2. 02 / ANALISAR
    Diagnóstico

    Rode o score de SEO na sua página e nas deles. A diferença é a sua pauta.

    → Lista de lacunas
  3. 03 / ESCREVER
    Produção

    Gere titles, metas, headings e a página inteira a partir das lacunas reais.

    → Copy que ranqueia
  4. 04 / OTIMIZAR
    Refino

    Passe a página pelo otimizador: headline, CTA, hierarquia e caminho de conversão.

    → Página ajustada
  5. 05 / CONVERTER
    Atrito

    Audite formulário, CTA e sinais de confiança. Remova o que faz o visitante desistir.

    → Funil sem vazamento
  6. 06 / AMPLIFICAR
    Alcance

    Converta o conteúdo em 30 dias de posts por plataforma. O tráfego volta para a página.

    → Ciclo que reinicia

O passo 6 realimenta o passo 1. É esse retorno que torna o sistema um ciclo, e não uma entrega única.

03 Metodologia Vibe Design Três verbos

Extrair.
Recombinar.
Construir.

O método que separa "fazer um site bonito" de "projetar um sistema". Você aprende a ler as decisões por trás de um site de referência, transformá-las em variáveis e escrevê-las como código — o mesmo processo que estruturou a identidade deste produto.

PASSO 01

Extrair

A API de Extração traz os dados brutos. O método ensina a ler decisões por trás deles: paleta com função, escala tipográfica, ritmo de espaçamento, densidade, tom de voz. O "Prompt de Mil Dólares" devolve isso já em tokens CSS.

PASSO 02

Recombinar

Cada decisão vira uma variável solta. Você troca as peças entre referências diferentes até o resultado não lembrar nenhuma delas — com registro de origem, porque método sem rastreabilidade vira cópia.

PASSO 03

Construir

Tokens → primitivas → componentes → página. Página por página é artesanato; sistema é o que permite atender dez clientes com a mesma equipe de um.

Nota sobre ética em design. Extrair um sistema (proporções, paleta, ritmo) é aprendizado legítimo. Copiar ativos — logotipo, ilustração, fotografia, código ou texto literal — é violação de direito autoral. O curso ensina a linha entre os dois, e o Design System Starter Kit entregue contém apenas sistemas originais derivados, sem nenhum ativo de terceiro.
