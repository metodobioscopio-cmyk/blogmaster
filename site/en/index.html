03Vibe Design Method Three verbs

Extract.
Recombine.
Build.

The method that separates "making a pretty site" from "designing a system". You learn to read the decisions behind a reference site, turn them into variables and write them as code — the same process that structured this product's identity.

STEP 01

Extract

The Extraction API brings raw data. The method teaches you to read the decisions behind it: palette with function, type scale, spacing rhythm, density, tone of voice. The "Thousand-Dollar Prompt" returns it as CSS tokens.

STEP 02

Recombine

Every decision becomes a loose variable. You swap pieces across references until the result resembles none of them — with provenance recorded, because a method without traceability becomes copying.

STEP 03

Build

Tokens → primitives → components → page. Page by page is craftwork; a system is what lets you serve ten clients with the team of one.

A note on design ethics. Extracting a system (proportions, palette, rhythm) is legitimate learning. Copying assets — logos, illustration, photography, code or literal text — is copyright infringement. The course teaches where the line sits, and the Design System Starter Kit ships only original derived systems, with no third-party assets.
