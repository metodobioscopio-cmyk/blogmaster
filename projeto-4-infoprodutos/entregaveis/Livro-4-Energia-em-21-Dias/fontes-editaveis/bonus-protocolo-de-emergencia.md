# BÔNUS 6 — Protocolo de Emergência para Noites Ruins

**Uma página. Imprima, dobre e deixe na cabeceira.** Use na manhã seguinte à noite ruim — não durante a noite.

```
+---------------------------------------------------------------------------+
|  PROTOCOLO DE EMERGENCIA — NOITE RUIM                                     |
|  Regra 1: nao durma mais para compensar. A recuperacao e na manha.        |
+---------------------------------------------------------------------------+
|  AO ACORDAR (faca nesta ordem, em 30 minutos)                             |
|                                                                            |
|  1. LEVANTE no horario combinado                                          |
|        ficar 40 min a mais na cama nao devolve o sono e atrasa o relogio   |
|                                                                            |
|  2. LUZ 10 a 15 minutos (mais que o normal)                               |
|        varanda, rua, trajeto aberto - a luz resgata o dia                  |
|                                                                            |
|  3. AGUA e comida de verdade no cafe da manha                             |
|        nao so cafe: proteina + carboidrato (capitulo 7)                    |
|                                                                            |
|  4. CAFEINA: NAO aumente a quantidade                                           |
|        se possivel, adie o primeiro cafe em 60 a 90 min depois de acordar  |
|        e mantenha o horario X da tarde                                     |
|                                                                            |
|  5. UMA TAREFA no periodo da manha                                        |
|        escolha a mais importante e faca antes do almoco, sem notificacao   |
|                                                                            |
|  6. MOVIMENTO curto a tarde (5 a 10 min de caminhada com luz)              |
|        em vez de um cafe extra                                             |
|                                                                            |
|  7. SONECA: no maximo 20 min e antes das 15h                              |
|                                                                            |
|  8. A NOITE SEGUINTE e normal: descarga mental + preparar o amanha +       |
|        sinal de sono. Deite no horario habitual.                          |
+---------------------------------------------------------------------------+
|  NAO FACA                                                                  |
|   x dormir 11 horas na noite seguinte                                      |
|   x tirar soneca longa a tarde                                             |
|   x tomar cafe extra a tarde                                               |
|   x cancelar tudo e passar o dia na cama                                   |
+---------------------------------------------------------------------------+
|  SE A NOITE RUIM VIROU PADRAO (3 ou mais por semana, por 2 semanas)        |
|  -> volte ao capitulo 10 (reconstrucao) E procure um profissional de       |
|     saude para avaliar o seu caso. Isso nao e fraqueza.                    |
|  Sofrimento emocional intenso: CVV 188 (24h, gratuito).                    |
+---------------------------------------------------------------------------+
```

## A frase da noite seguinte

> "Hoje foi ruim. Amanhã começa com luz, no horário de sempre — e o dia volta a ser meu."

Diga isso quando chegar em casa. Não é frase de efeito: é o resumo do único procedimento que realmente funciona depois de uma noite ruim — **manter a âncora quando seria mais fácil abandoná-la**.

> 📌 **NOTA — o que a emergência não resolve.**
> Este protocolo organiza o dia seguinte a uma noite ruim. Ele **não** avalia por que a noite foi ruim. Se as noites ruins se repetem, o caminho é o capítulo 9 (mente) e a avaliação profissional descrita no aviso da abertura. Rotina organiza; ela não substitui cuidado.
