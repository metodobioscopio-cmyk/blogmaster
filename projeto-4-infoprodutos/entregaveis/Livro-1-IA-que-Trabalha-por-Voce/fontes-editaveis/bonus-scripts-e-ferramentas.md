# PARTE 1 · Os 5 scripts de abordagem

> Regra: **personalize sempre**. Mensagem genérica copiada para 50 pessoas tem resultado pior que 10 mensagens escritas para o caso daquela pessoa. Comece sempre pelo nome e por algo concreto do negócio/situação dela.

### Script 1 — Conhecido (WhatsApp)
```
Oi [nome], tudo bem? Vou te contar uma coisa que comecei a fazer:
eu [ajudo X a resolver Y] usando IA — entrega rápida e com preço fechado.

Fiz um exemplo do que seria no seu caso: [descreva ou envie o print].
Se fizer sentido, eu faço a primeira parte sem cobrar para você ver o resultado.
Quer?
```
**Não escreva:** "estou começando e preciso de clientes", "está baratinho", "qualquer valor tá bom".

### Script 2 — Comércio local (presencial ou DM)
```
Boa tarde! Sou [nome], moro aqui na região.
Vi o perfil de vocês no Instagram — as fotos estão boas, mas as descrições
estão curtas e o produto acaba sumindo na busca.

Eu escrevo descrições otimizadas e legendas que aparecem melhor.
Posso fazer 3 descrições de amostra hoje, sem custo, para você avaliar?
```

### Script 3 — Colega / ex-colega / LinkedIn
```
Oi [nome], vi que você trabalha com [área].
Eu ajudo profissionais a ganhar tempo em [tarefa específica — relatório,
proposta, ata, conteúdo] com apoio de IA.

Tenho um pacote de [entregáveis] por R$ [valor], com entrega em [prazo].
Te mostro como ficaria no seu caso?
```

### Script 4 — Follow-up (48 h depois, para quem não respondeu)
```
Oi [nome], só para não perder o fio: a amostra ficou pronta e ficou boa.
Quer que eu mande por aqui ou prefere que eu passe aí?
```
**Máximo de 2 follow-ups.** Insistir mais queima a ponte.

### Script 5 — Pós-entrega (depoimento + indicação + recompra)
```
Fico feliz que gostou, [nome]!
Dois pedidos rápidos:
1) Você conhece alguém que também precisaria disso? Me apresenta?
2) No mês que vem abro 3 vagas de [serviço mensal], R$ [valor].
   Quer que eu guarde uma para você?
```

# PARTE 2 · Ficha de Contexto Mestre (cole no começo de todo prompt)

```
CONTEXTO MESTRE

Quem sou: [nome, profissão, cidade]
Onde trabalho: [empresa/segmento/tamanho/meu papel]
Meu público: [quem é, o que precisa, o que teme]
Meu tom de voz: [ex.: direto e cordial, sem gírias, sem emoji]
Palavras que eu nunca uso: [ex.: alavancar, robusto, sinergia]
O que eu nunca quero na resposta: [ex.: promessa de resultado, jargão técnico]
Formato padrão: [ex.: até 150 palavras, em tópicos, terminando com próximo passo]
Dados que não podem aparecer: [ex.: nome de cliente, valores reais, prontuário]
Regra permanente: se faltar informação, pergunte antes de responder;
se não tiver certeza de fato/número, avise que é suposição.
```

**Dica:** configure isso nas "instruções personalizadas" / "projeto" / "GPT personalizado" da sua ferramenta. Você para de repetir e a qualidade sobe.

# PARTE 3 · Glossário pessoal (ensine seu estilo à IA)

| Nunca usar | Usar em vez disso |
|---|---|
| "Prezado" | "Oi [nome]," |
| "Venho por meio desta" | "Escrevo para..." |
| "Alavancar", "sinergia", "robusto" | "melhorar", "integração", "confiável" |
| "Solução" (vago) | o nome do que você entrega |
| Emoji em e-mail profissional | nenhum (ou só em WhatsApp) |
| "Qualquer dúvida, estou à disposição" | "Me diga o que precisa e eu ajusto" |

# PARTE 5 · Controle de Horas Economizadas

| Data | Tarefa | Tempo antes | Tempo agora | Ganho | Valor do ganho (R$) | O que fiz com o tempo |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |

**Fórmulas:**
```
Ganho (min) = Tempo antes − Tempo agora
Valor do ganho = (Ganho ÷ 60) × valor da sua hora
Total do mês = soma da coluna "Ganho"
```

**Metas de referência:**
- Mês 1: 6 a 10 horas economizadas
- Mês 2: 12 a 18 horas
- Mês 3: 20+ horas (aí parte delas vira renda extra)

# PARTE 7 · Checklist "Publiquei seguro?"

- [ ] Revisei o conteúdo e ele reflete o que eu penso
- [ ] Não há dado pessoal ou sigiloso de terceiros
- [ ] Não há afirmação que eu não possa comprovar
- [ ] Nenhuma promessa de resultado garantido
- [ ] Imagens com licença ou próprias/geradas
- [ ] Nada copiado sem crédito
- [ ] Sem estereótipo ou generalização sobre pessoas
- [ ] Decisões que envolvem gente foram humanas
- [ ] Avisei quando era necessário avisar
- [ ] Arquivo salvo e data de revisão marcada
