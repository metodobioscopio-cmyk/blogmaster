### Se um link não abrir
1. **Página do arquivo:** abra a pasta [`projeto-4-infoprodutos/downloads/`](.) e clique no arquivo → botão **Download**.
2. **Pelo Git (para quem tem o repositório clonado):**
   ```bash
   git pull
   # os arquivos estão em projeto-4-infoprodutos/downloads/
   ```
3. **Regenerar tudo do zero** (leva ~30 segundos):
   ```bash
   pip install --break-system-packages reportlab imageio-ffmpeg
   python3 tools/gerar_livros.py && python3 tools/gerar_downloads.py && python3 tools/gerar_pacote_full.py
   ```
