# FERRAMENTA 2 · Calculadora de Capacidade Real de Pagamento (CRP)

```
PASSO 1 — Renda líquida mensal ................... R$ ______
PASSO 2 — Parcela máxima segura (20% da renda) ... R$ ______
PASSO 3 — Valor à vista disponível:
          reserva "Guerra" ....................... R$ ______
        + renda de apoio em 30 dias .............. R$ ______
        = disponível à vista ..................... R$ ______

PASSO 4 — Teto de parcela geral (todos os acordos somados)
          até 20% da renda ....................... R$ ______
          alarme: acima de 30% = risco alto de recaída
```

**Teste do mês ruim:** *"Se eu tiver um imprevisto de R$ 400, essa parcela continua caindo?"*
- Sim → pode assinar
- Não → reduza a parcela antes de fechar

# FERRAMENTA 4 · Checklist de Acordo Seguro (use antes de pagar)

Antes de transferir qualquer valor, confirme:

- [ ] A proposta chegou **por escrito** (e-mail, plataforma, contrato digital)
- [ ] Consta o **nome do credor atual** e o número do contrato/dívida
- [ ] Consta o **valor total** da dívida e o **valor negociado**
- [ ] Consta o **número de parcelas** e o **vencimento de cada uma**
- [ ] Consta o que acontece **em caso de atraso** (multa? perda do desconto?)
- [ ] Consta o **prazo e a condição de retirada do apontamento** após a quitação
- [ ] O **canal de pagamento é oficial** do credor (não é Pix de pessoa física)
- [ ] Eu **li o documento inteiro** e entendi todas as cláusulas
- [ ] A **parcela cabe no mês ruim** (teste da Ferramenta 2)
- [ ] Vou **guardar** proposta, comprovantes e protocolos por 5 anos

> Se qualquer item estiver em branco: **não pague ainda.**

# FERRAMENTA 5 · Planilha Bola de Neve (com projeção)

| Ordem | Dívida | Saldo atual | Parcela mínima | Extra do mês | Total do mês | Saldo após o mês | Meses restantes |
|---|---|---|---|---|---|---|---|
| 1º | | R$ | R$ | R$ | R$ | R$ | |
| 2º | | R$ | R$ | R$ | R$ | R$ | |
| 3º | | R$ | R$ | R$ | R$ | R$ | |

**Regras:**
1. Todas as dívidas recebem o **mínimo**.
2. Todo o **extra** vai para a **primeira da fila**.
3. Quando uma é quitada, o valor dela **se soma** ao ataque da próxima.
4. A ordem segue o critério híbrido: 🔴 risco → menor dívida → maior juros → restante.

**Gráfico de progresso (atualize todo mês):**
```
Mês 1  |▓░░░░░░░░░|  5%
Mês 2  |▓▓░░░░░░░░| 11%
Mês 3  |▓▓▓░░░░░░░| 18%
```

# FERRAMENTA 7 · Protocolo de cobrança abusiva (registro de provas)

Preencha sempre que sofrer cobrança fora do razoável:

| Data | Hora | Credor/cobradora | Nome de quem falou | O que aconteceu | Provas (áudio/print/nº) |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |

**Tipos de abuso a registrar (conforme art. 42 e art. 71 do CDC):**
- Ameaça, coação ou constrangimento
- Exposição a ridículo
- Comunicação a terceiros (trabalho, vizinhos, familiares)
- Afirmações falsas ou enganosas
- Ligações que interferem no trabalho, descanso ou lazer

**Depois de registrar:** abra reclamação no canal oficial do credor, no consumidor.gov.br e/ou no Procon. Reclamação com prova organizada tem muito mais força. Em casos graves, procure advogado ou Defensoria.
