# Templates

Planilhas e fichas prontas para acompanhar a produção. Todas abrem no Excel, Google Sheets ou LibreOffice.

| Arquivo | Para que serve |
|---|---|
| `calendario-30-dias.csv` | O plano dia a dia (fase 1) — marque "Feito?" conforme avança |
| `planilha-mestre-pins.csv` | Inventário de todos os pins: título, descrição, arquivo, board, destino, status |
| `tracker-metricas.csv` | Métricas semanais com colunas de CTR, conversão e RPM |
| `ficha-validacao-de-oferta.md` | A ficha de 12 critérios para validar cada oferta antes de produzir |
| `checklist-publicacao.md` | O que conferir antes de cada lote (visual, SEO, compliance) |

## Como usar no dia a dia

1. **Antes de começar:** preencha uma `ficha-validacao-de-oferta.md` para cada oferta candidata.
2. **Durante a produção:** o app gera o pack e você exporta em CSV (botão "Exportar CSV" na etapa 9) — cole na `planilha-mestre-pins.csv`.
3. **Antes de publicar:** passe pelo `checklist-publicacao.md`.
4. **Toda segunda:** uma linha no `tracker-metricas.csv`.

> 💡 O app já faz tudo isso automaticamente. Os templates existem para quem prefere trabalhar fora dele ou para manter um backup dos dados.
