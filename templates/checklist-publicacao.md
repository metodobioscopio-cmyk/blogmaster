# Checklist de Publicação — rode antes de CADA lote

## Por pin

- [ ] Imagem em 1000×1500 px (2:3) ou 1080×1920 (vídeo 9:16)
- [ ] Overlay com 5 a 8 palavras, bold, alto contraste
- [ ] Teste do brilho a 30% passou
- [ ] Um único foco visual
- [ ] Sem borda grossa, sem marca d'água de outra rede
- [ ] Sem "cara de IA" óbvia (mãos, dentes, texto torto)
- [ ] Texto dentro da margem de segurança (8-10%)
- [ ] Arquivo renomeado com a palavra-chave (`palavra-chave-1.png`)
- [ ] Título de 40 a 60 caracteres com a keyword
- [ ] Descrição de 2 a 4 linhas naturais
- [ ] Alt text preenchido
- [ ] Máximo 5 hashtags
- [ ] Board relevante e com keyword no título/descrição

## Por pin com oferta (afiliado)

- [ ] Aviso de transparência na descrição
- [ ] Link completo (sem encurtador)
- [ ] Link testado em janela anônima
- [ ] Promessa do pin = conteúdo da página
- [ ] UTM de campanha na URL
- [ ] Página de destino avisa antes do primeiro link
- [ ] Nenhuma promessa de resultado irreal

## Por lote

- [ ] Nenhum board recebeu 2 pins do mesmo link no mesmo dia
- [ ] Mínimo 72h entre pins do mesmo link
- [ ] Proporção 80/20 respeitada (80% útil, 20% oferta)
- [ ] Mix de formato: 60-70% estático, 20-30% vídeo, ~10% carrossel
- [ ] Volume total do dia ≤ 5 pins
- [ ] Nada de 150+ links de afiliado no dia
- [ ] Pins registrados na planilha mestre

## Semanal

- [ ] Métricas anotadas (impressões, cliques, saves, vendas, receita)
- [ ] Comparação com a semana anterior
- [ ] Estoque de pins para os próximos 7 dias ≥ 15
- [ ] Nenhum aviso novo na conta
