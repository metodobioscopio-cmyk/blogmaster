# Bridge & Better — Método de validação usado nos 10 produtos

Como validamos sem gastar em ads: **achar quem já vende → ler reviews 3–4★ → lançar versão melhor e nichada.**

## Passo 1 — Garimpo (30min/produto)

Buscar exatamente assim (ordenar por best-seller / top rated):

- **Etsy:** `notion template freelancer`, `ai prompt bundle`, `budget spreadsheet`, `adhd planner`, `faceless marketing playbook`, `content calendar`, `automation playbook`, `resume template canva`, `side hustle ebook`, `canva social media kit`
- **Gumroad Discover:** mesmos termos + `notion`, `prompts`, `planner`
- **Product Hunt:** `notion template`, `ai prompts`, `finance tracker`
- **ClickBank Marketplace:** filtrar Gravity > 20 em Business/Marketing/Self-help
- **PromptBase / Etsy digital:** para precificar prompt packs ($9–$29)

Salvar em planilha: nome, preço, nº reviews, rating, link, 3 bullets da oferta.

Critério de VALIDAÇÃO: ≥2 concorrentes com 100+ vendas/reviews OU 1 com 1000+ vendas. Todos os 10 deste repo passam.

## Passo 2 — Ouro nas 3–4★ (45min)

Filtre reviews 3 e 4 estrelas. Ignore 5★ (genéricas) e 1–2★ (raiva). Extraia frases literais:

Padrões que se repetem nos 10 nichos:

| Falha citada | Frequência | Nosso fix padrão |
|---|---|---|
| "Good but no video tutorial, got lost" | altíssima (Notion/Sheets/Automação) | vídeo Loom 5–15min + quickstart 1 página |
| "Too generic, not for my niche X" | alta (prompts, marketing, resume) | versão nichada: freelancer / creator / coach / student |
| "Design is cluttered / ugly" | alta (Notion, Canva, Sheets) | UI minimalista, 2 fontes, 3 cores, mobile-friendly |
| "No examples filled in" | média | banco de exemplos pré-preenchidos + dummy data |
| "No updates / outdated prompts" | média (AI) | promise de updates + changelog + versão datada |
| "Hard to customize" | média | guia "make it yours in 20min" + presets |

Cada DOSSIER traz a tabela Bridge & Better específica do produto.

## Passo 3 — Diferenciação mínima viável (regra: 3 fixes)

Todo produto deste repo tem **obrigatoriamente ≥3** destes:

1. [ ] Vídeo setup/demo (Loom, faceless, narração IA ok)
2. [ ] Nicho explícito no título (ex: "for Freelancers", "for Creators", "for ADHD")
3. [ ] UI minimalista + mobile check
4. [ ] Exemplos pré-preenchidos / dummy data
5. [ ] Bônus calculável (planilha, tracker, script, blueprint importável)
6. [ ] Updates vitalícios + changelog visível na sales page
7. [ ] Licença comercial clara (pode usar para clientes, não pode revender)

## Passo 4 — Precificação Bridge

- Concorrente Etsy barato ($5–$12) → nós $19–$29 com vídeo + bônus (âncora "premium done-for-you").
- Concorrente Gumroad médio ($19–$39) → nós igual, mas com Plus variant + bundle.
- Nunca competir por preço. Competir por **clareza + setup rápido + prova**.

## Passo 5 — Prova rápida antes do launch

- Beta com 3–5 pessoas (Reddit, Discord, X): acesso grátis em troca de Loom de 2min usando + depoimento.
- Print de antes/depois conta como prova. Não precisa "faturei $10k".
- 3 depoimentos > 0 depoimentos. Launch com 3.
