# 08 · Compliance e Risco — o que derruba contas (e como não perder a sua)

> Este capítulo parece chato. É o que separa quem fatura por 5 anos de quem perde a conta no mês 3.

---

## 8.1 A regra base do Pinterest sobre afiliados

O Pinterest **permite** conteúdo de afiliado. A formulação oficial vai nesta direção:

> *"Conteúdo de afiliado deve ser original e agregar valor único para os Pinners. Seja transparente sobre a natureza comercial do seu conteúdo e sobre seus links e o comportamento deles. Alguns serviços de encurtamento não são suportados — se o link do seu Pin estiver bloqueado, você pode editá-lo."*

Traduzindo em regras operacionais:

| ✅ Permitido | ❌ Proibido / penalizado |
|---|---|
| Link de afiliado no campo de destino do pin | Encurtadores (bit.ly, tinyurl, cutt.ly) |
| Link de afiliado em descrição, com aviso | Afiliado sem revelar a relação comercial |
| Pins de afiliado balanceados com conteúdo útil | Padrão repetitivo e em massa de pins promocionais |
| Amazon, Hotmart, Kiwify, ShareASale, ClickBank etc. | Página de destino com excesso de anúncios |
| Link para o seu blog com afiliados dentro | Produtos de categoria proibida |
| Comparativos e resenhas | Alegações enganosas sobre o produto |

### A regra do 80/20
**80% conteúdo útil e não promocional / 20% pins de oferta direta.** Contas que só empurram produto são penalizadas. Isso não é etiqueta — é mecanismo de distribuição.

## 8.2 Transparência: a exigência legal (não é opcional)

Tanto as diretrizes de plataforma quanto as regras de publicidade (FTC nos EUA, e o princípio de transparência do CDC no Brasil) exigem que a relação comercial esteja **clara e perto do link**.

### Modelos prontos (copie)

**Na descrição do pin:**
```
Este conteúdo contém link de afiliado. Se você comprar por ele, eu posso
receber uma comissão, sem nenhum custo extra para você. #afiliado #ad
```

**Na página de destino (antes do primeiro link):**
```
AVISO DE PUBLICIDADE
Esta página contém links de afiliado. Se você comprar através deles, eu posso
receber uma comissão sem custo adicional para você. Isso não influencia o preço
que você paga.

Como associado(a) [Amazon/plataforma], eu ganho por compras qualificadas.
```

**Em inglês:**
```
This post contains affiliate links. If you buy through them, I may earn a
commission at no extra cost to you. #affiliate #ad

As an Amazon Associate I earn from qualifying purchases.
```

> ⚠️ **Detalhe técnico que muita gente erra:** o aviso precisa estar **antes** do link, não escondido no rodapé, e não pode ser fonte minúscula cinza-claro. Se for preciso rolar para achá-lo, não conta como aviso.

## 8.3 Os bloqueios absolutos (isso derruba ou limita a conta)

| ❌ Nunca faça | Consequência real |
|---|---|
| Produtos de **arma, munição, tabaco, vape, álcool destilado** | Remoção + possível suspensão |
| Conteúdo **adulto** ou sexualmente sugestivo | Suspensão da conta |
| **Aposta / jogos de azar** não licenciados | Suspensão |
| **Suplementos com alegação de cura** ("cura diabetes", "elimina o câncer") | Remoção + risco jurídico |
| **Promessa de renda** ("ganhe R$ 5.000 por semana garantido") | Remoção + risco jurídico |
| **Antes/depois** de emagrecimento extremo ou "resultado em 3 dias" | Remoção |
| **Encurtador de link** | Link bloqueado, pin marcado como spam |
| **Marca d'água** de TikTok/Instagram em vídeo | Redução de alcance |
| **Cópia 1:1** de criativo de concorrente | Denúncia de DMCA |
| **Automação** que publica sem consideração individual | Violação de diretriz de desenvolvedor |
| Publicar o **mesmo link** dezenas de vezes por dia | Filtro de spam |
| **Mais de 150 links de afiliado/dia** | Padrão de spam automatizado |

## 8.4 Links: as 6 regras de ouro

1. **Nunca use encurtador.** Cole a URL completa do afiliado. Se quiser rastrear, use parâmetros UTM na sua própria página — isso é permitido.
2. **Confirme se o programa permite link direto em redes sociais.** Alguns exigem intermediação (Etsy é o caso clássico: os termos de afiliado não permitem postar link direto no Pinterest — é preciso um blog/post no meio).
3. **Teste todo link em janela anônima** antes de publicar. Link quebrado derruba a confiança do domínio.
4. **Um destino por pin.** Não coloque 3 links diferentes na mesma descrição.
5. **A promessa do pin tem que casar com a página.** Pin sobre "organização de cozinha" que leva para "curso de marketing" = queda de relevância.
6. **Mantenha 72h de intervalo** entre pins que apontam para a mesma URL.

## 8.5 Imagens e IA: o que você pode usar comercialmente

| Ferramenta | Uso comercial no plano grátis | Observação |
|---|---|---|
| **Adobe Firefly** (modelos próprios) | ✅ Sim | Treinado em conteúdo licenciado — o mais seguro juridicamente |
| **Ideogram** | ✅ Sim (confirme os termos atuais) | Verifique restrições de conteúdo |
| **Leonardo AI** | ✅ Sim, licença não exclusiva | Outputs do plano grátis ficam públicos |
| **Bing Image Creator** | ⚠️ Verifique | Os termos do Designer de consumidor restringem uso comercial |
| **Kling / Hailuo (vídeo)** | ❌ Não no grátis | Exige plano pago para uso comercial |
| **CapCut (desktop)** | ✅ Sim, para conteúdo seu | Livre de marca d'água |
| **Canva grátis** | ✅ Sim, para os seus designs | Sujeito aos termos do Canva |

**Regras de segurança:**
- Nunca gere **pessoa real, celebridade ou personagem protegido**.
- Nunca gere **logo de marca** em contexto que sugira endosso.
- Nunca use foto de terceiro (Google Imagens, Instagram) sem licença.
- Se o seu negócio crescer, migre a produção de imagem para Firefly (ou equivalente com licença clara) para ter rastreabilidade.

## 8.6 O que fazer se você receber um aviso

**Plano de recuperação, em ordem:**

1. **Não recorra no impulso.** Espere 24h. Recursos emocionais raramente funcionam.
2. **Identifique o padrão.** Abra o painel de avisos e leia qual regra foi citada. Na maioria dos casos é: (a) encurtador, (b) conteúdo afiliado sem transparência, (c) volume/repetição, (d) categoria proibida.
3. **Corrija TODOS os pins afetados** — não só o pin denunciado. Se um encurtador foi o problema, troque em todos.
4. **Pause publicações por 72 horas.** Deixe a conta "respirar". Continue salvando conteúdo de terceiros e interagindo normalmente.
5. **Reduza o volume** e aumente a proporção de conteúdo não promocional (volte para 80/20).
6. **Volte em ritmo reduzido:** 1-2 pins/dia por 2 semanas, aumentando gradualmente.
7. **Se for suspensão**, use o formulário oficial de recurso na Central de Ajuda, seja objetivo, assuma o erro específico, descreva a correção e mostre que já implementou.
8. **Plano B sempre pronto:** mantenha um segundo nicho mapeado e 2 ofertas alternativas. Dependência de uma única conta é risco de negócio, não de plataforma.

**O que NÃO fazer:** criar conta nova para contornar punição. Isso é evasão de banimento e resulta em banimento permanente do dispositivo/rede.

## 8.7 Autoauditoria mensal de 10 perguntas

Rode todo dia 1º do mês. Se qualquer resposta for "não" ou "não sei", corrija antes de continuar.

```
1. Todos os meus pins de afiliado têm aviso de transparência visível?
2. Minha página de destino avisa ANTES do primeiro link?
3. Nenhum link encurtado em uso?  (conferi os últimos 20 pins)
4. Testei os 10 links mais clicados em janela anônima este mês?
5. Algum produto que promovo entrou em categoria proibida?
6. Estou respeitando o 80/20 (conteúdo útil vs promocional)?
7. Estou mantendo 72h+ entre pins do mesmo link?
8. Meu volume diário está abaixo de 150 links de afiliado?
9. Confirmei os termos atualizados dos meus programas de afiliado?
10. Tenho um segundo nicho e uma segunda oferta mapeados?
```

## 8.8 Tabela de risco por decisão

| Decisão | Risco | Nível | Mitigação |
|---|---|---|---|
| Link direto de afiliado no pin | Programa pode proibir | 🟡 Médio | Confirme os termos; use página intermediária se houver dúvida |
| Link via página própria | Quase nenhum | 🟢 Baixo | Método recomendado |
| Usar 5 hashtags | Nenhum | 🟢 Baixo | Máximo 5 |
| Usar 30 hashtags | Filtro de spam | 🔴 Alto | Nunca |
| Publicar 3-5 pins/dia | Nenhum | 🟢 Baixo | Faixa segura |
| Publicar 50 pins/dia | Marcação como spam | 🔴 Alto | Não faça |
| Vídeo gerado com IA grátis | Licença não comercial | 🟡 Médio | Anime você mesmo no CapCut |
| Imagem de gerador com uso comercial | Nenhum | 🟢 Baixo | Prefira Firefly/Ideogram/Leonardo |
| Promover infoproduto de saúde | Alegação médica | 🔴 Alto | Nunca prometa cura |
| Produto físico via Amazon | Cookie de 24h | 🟡 Médio | Escolha produto de compra por impulso |
| Programa com mensalidade de inatividade | Custo silencioso | 🟡 Médio | Só entre com volume |
